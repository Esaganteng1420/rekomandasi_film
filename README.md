🎬 Rekomendasi Film

Aplikasi Rekomendasi Film adalah aplikasi berbasis Flutter yang digunakan untuk menampilkan daftar film beserta informasi dan detailnya.

✨ Fitur Aplikasi

* Menampilkan daftar film.
* Menampilkan poster film.
* Menampilkan judul dan genre film.
* Menampilkan rating film.
* Menampilkan detail dan sinopsis film.
* Menampilkan informasi film berdasarkan data JSON.

🛠️ Teknologi

* Flutter
* Dart
* JSON
* Visual Studio Code

🚀 Cara Menjalankan Aplikasi

1. Clone repository:

git clone https://github.com/USERNAME/rekomendasi_film.git

2. Masuk ke folder proyek:

cd rekomendasi_film

3. Install dependencies:

flutter pub get

4. Jalankan aplikasi:

flutter run

📱 Build APK

Gunakan perintah:

flutter build apk --release

File APK akan tersedia di:

build/app/outputs/flutter-apk/app-release.apk
